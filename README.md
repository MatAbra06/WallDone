# WallDone - Business Landing Page 🛠️

A responsive, client-facing landing page developed for a local construction and interior finishing business. This is a legacy project that was successfully deployed and utilized during the company's operational period.

## 🛠️ Tech Stack & Features
- **Frontend:** HTML5, CSS3, JavaScript.
- **Responsive Web Design (RWD):** Fully optimized for mobile, tablet, and desktop devices.
- **UI/UX Focus:** Clean layout, structured service presentation, and an intuitive contact form to drive customer engagement.

## 💼 Business Logic & Context
As a freelancer, I was responsible for the entire lifecycle of this project:
1. Gathering requirements and analyzing the client's business niche.
2. Designing the visual layout and content structure.
3. Writing clean, maintainable frontend code and deploying the website.

*Note: This repository represents the complete codebase of a past commercial project. The live website has been decommissioned following the closure of the client's business.*
